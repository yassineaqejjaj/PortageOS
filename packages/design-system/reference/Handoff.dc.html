Responsive

≥ 1280 sidebar 248 + topbar + contenu ; drawer droit 480 en split.

600–1279 sidebar réduite 72 (icônes + tooltip) ; drawer en superposition ; tableaux : colonnes secondaires masquées, menu « Colonnes ».

≤ 599 portails consultant/client uniquement + Operations essentielles ; navigation basse 4 entrées ; tableaux → listes de cartes ; actions en barre basse collante, cibles 44 px.

Composants : .app flex-wrap (sidebar empilée), .split 999/1, grilles 4→2→1.

Accessibilité (WCAG 2.2 AA)

Focus visible 2 px color.border.focus, offset 2.

Statut = icône de forme + texte + couleur ; jamais couleur seule.

Tableaux : th scope, tri annoncé, sélection au clavier (Espace), drawer piège le focus et rend le focus à la ligne.

Agents : changements de statut via aria-live="polite" ; Pause/Stop atteignables au clavier en permanence.

Cibles ≥ 24 px desktop, 44 px mobile ; pas de délai imposé sauf session (préavis 2 min).

Ton & formats

Vouvoiement ; verbes d'action dans les boutons (« Valider 19 jours », pas « OK »).

Erreurs : ce qui s'est passé + pourquoi + quoi faire, avec code incident.

IA : « préparé par », « suggestion », « estimation » ; jamais « l'IA a décidé ».

Montants Intl.NumberFormat('fr-FR', {style:'currency', currency:'EUR'}) ; dates dd/MM/yyyy ; HT/TTC toujours précisés.

Seuils légaux : toujours depuis RuleEngine avec version affichée.
