# Contribuer
1. Lire `CLAUDE.md` (règles impératives) et `docs/ENGINEERING.md`.
2. Branche `feat/...` ou `fix/...`, PR vers `main`, CI verte obligatoire.
3. Une fonctionnalité n'est « terminée » que si la liste de la PR est cochée. Mettre à jour `docs/IMPLEMENTATION_MATRIX.md` avec la preuve (fichiers, tests).
4. Commits : impératif court, corps = pourquoi. Pas de secrets, pas de données réelles.
5. Règles légales : ajoutées uniquement depuis une source officielle citée, avec validation humaine (voir `docs/DOMAIN_RULES.md`).
